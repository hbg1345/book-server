Session-based user API. Log in via `POST /api/auth/login`; the session cookie then
identifies the current user on the `+/api/users/me+` endpoints.

== User

=== Register

Creates a new user. The raw password is sent in plaintext over the request and stored
hashed (never in plaintext). Returns the generated `userUuid`.

`POST /api/users`
